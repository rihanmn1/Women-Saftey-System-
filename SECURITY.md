# Security Policy

## Supported version

Security fixes are applied to the latest commit on the default branch. This project is currently a prototype and does not publish supported production releases.

## Report a vulnerability

Do not open a public issue for a vulnerability that could expose personal data, enable unauthorized device configuration, or create a false sense that an emergency action succeeded.

Use GitHub's private vulnerability reporting feature if it is enabled. Otherwise, contact the repository owner privately through the contact method on their GitHub profile. Include:

- A concise description and potential impact
- Reproduction steps or a minimal proof of concept
- Affected files or versions
- A suggested mitigation, if known

Do not include real phone numbers, credentials, precise locations, or data from people who did not consent to disclosure. Please allow reasonable time for investigation before public discussion.

## Scope notes

WISE sends browser requests to devices on a local network. Reports involving URL validation, unintended network access, personal-data exposure, misleading success states, or unauthorized device pairing are especially relevant.
